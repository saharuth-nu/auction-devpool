## วิธีอ่าน

- แต่ละข้อมีรหัสไม่ซ้ำ เช่น `BID-03` ใช้อ้างใน task, commit, test (เช่นชื่อ test ขึ้นต้นด้วยรหัส)
- ใช้คำว่า **"ต้อง"** = บังคับ, **"ควร"** = แนะนำ
- คอลัมน์สถานะ:
  - ✅ **ยืนยัน** = เจ้าของโปรเจคระบุหรือตอบรับแล้ว
  - ⚠️ **สมมติฐาน** = ผมเสนอเพื่อให้ครบ ยังรอเจ้าของโปรเจคยืนยัน ถ้าไม่เห็นด้วยให้แก้ข้อนั้นก่อนเริ่มทำส่วนที่เกี่ยวข้อง

## คำศัพท์

| คำ | ความหมาย |
|---|---|
| สินค้า (item) | ของที่นำมาประมูล |
| ห้องประมูล (room) | ห้องที่มีจำนวนผู้เข้าร่วมและจำนวนสินค้าสูงสุด |
| การประมูล / event | รอบการประมูลหนึ่งรอบ ผูกกับห้อง วิธีประมูล เวลา และสินค้า |
| lot | สินค้าหนึ่งชิ้นภายใน event หนึ่ง (เก็บผลชนะ/ไม่ขายของชิ้นนั้น) |
| เข้าร่วมประมูล | ผู้ใช้ลงทะเบียนสนใจสินค้าหนึ่ง (ต้องทำก่อนจึงยื่นราคาได้) |
| เข้าห้อง | ผู้ใช้เข้าห้องประมูลตอนถึงเวลาจริง |
| ยื่นราคา (bid) | ราคาลับที่ผู้ใช้เสนอ ครั้งเดียวต่อสินค้า |
| ราคาขั้นต่ำ (reserve) | ราคาต่ำสุดที่ยอมขาย ถ้าราคาสูงสุดต่ำกว่านี้ถือว่าไม่ขาย |
| ทรัพย์สิน | รายการทรัพย์สินที่ผู้ใช้แจ้ง (ชื่อ + มูลค่า) ใช้เป็นเพดานราคาที่ยื่นได้ |
