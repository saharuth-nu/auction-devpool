# 02 Module ฝั่ง Admin

หลัง login admin ต้องเห็นหน้าเลือก module: **สินค้าประมูล · วิธีการประมูล · ห้องประมูล · การประมูล · ตรวจสอบผู้ใช้ · ผู้ใช้ทั้งหมด · บัญชี admin · ประวัติการกระทำ (audit log)** (ตรวจสอบผู้ใช้ / ผู้ใช้ทั้งหมด / บัญชี admin อ้างถึงใน [01-accounts.md](01-accounts.md) · audit log ดู `NFR-17`–`NFR-18`)

## ITEM — สินค้าประมูล

| รหัส | Requirement | สถานะ |
|---|---|---|
| ITEM-01 | admin ต้องดูรายการ เพิ่ม แก้ไข ลบ สินค้าได้ | ✅ |
| ITEM-02 | สินค้ามีสถานะ **รออนุมัติ → พร้อมขาย → อยู่ระหว่างการประมูล → ขายได้แล้ว** | ✅ |
| ITEM-03 | รายการสินค้าต้องแสดง/กรองตามสถานะได้ | ✅ |
| ITEM-04 | สินค้าที่เพิ่มใหม่ต้องเริ่มที่ "รออนุมัติ" และ admin ต้องกด **อนุมัติ** เพื่อเปลี่ยนเป็น "พร้อมขาย" | ✅ |
| ITEM-05 | ตอนเพิ่มสินค้า admin ต้องกำหนด **ราคาเริ่มต้น** และ **ราคาขั้นต่ำ (reserve)** | ✅ |
| ITEM-06 | ราคาขั้นต่ำต้องไม่ต่ำกว่าราคาเริ่มต้น ราคาทั้งสองต้องมากกว่า 0 | ✅ |
| ITEM-07 | สินค้าต้องมีรูปได้ **มากกว่า 1 รูป** (อัปโหลดหลายไฟล์ ลบ/เรียงลำดับรูปได้) | ✅ |
| ITEM-08 | รูปรับเฉพาะ JPG/PNG/WebP ขนาดไม่เกิน 5 MB ต่อรูป และไม่เกิน 10 รูปต่อสินค้า | ✅ |
| ITEM-09 | สินค้าที่ "อยู่ระหว่างการประมูล" ต้องลบและแก้ราคาไม่ได้ | ✅ |
| ITEM-10 | สินค้าอยู่ได้ **event เดียวในเวลาเดียว** | ✅ |
| ITEM-11 | สินค้าที่ไม่ขาย (ดู BID-09) ต้องกลับเป็น "พร้อมขาย" และออกจาก event เพื่อนำไปใส่ event ใหม่ได้ | ✅ |
| ITEM-12 | สินค้าที่ **เคยอยู่ใน event ที่เริ่มแล้ว** (มีประวัติ lot/การเข้าร่วม/ราคาที่ยื่น) ต้อง **ลบจริงไม่ได้** ให้ใช้ "เก็บถาวร" แทน: ซ่อนจากรายการปกติและเลือกใส่ event ใหม่ไม่ได้ แต่ประวัติและหน้าผลยังแสดงสินค้านั้นได้ · ลบจริงได้เฉพาะสินค้าที่ไม่เคยอยู่ใน event ที่เริ่มแล้ว (ดู `NFR-19`) | ⚠️ |

## METH — วิธีการประมูล

| รหัส | Requirement | สถานะ |
|---|---|---|
| METH-01 | admin ต้องดูรายการวิธีประมูลได้ | ✅ |
| METH-02 | admin ต้องเพิ่มวิธีประมูลได้ | ✅ |
| METH-03 | admin ต้อง **เปิด/ปิดใช้งาน** วิธีประมูลได้ | ✅ |
| METH-04 | ใน M1 ต้องมีวิธี `first_price` (first-price sealed) เป็นวิธีเดียวที่ทำงานได้จริง | ✅ |
| METH-05 | โครงสร้างต้องรองรับเพิ่มวิธีอื่น (english, dutch) ในอนาคตโดยไม่รื้อ event/lot/bid | ✅ |
| METH-06 | วิธีประมูลที่ปิดใช้งาน ต้องเลือกตอนสร้าง event ใหม่ไม่ได้ (event เดิมไม่กระทบ) | ✅ |
| METH-07 | ระยะเวลายื่นราคา (30 วินาที) ต้องเป็นค่ากำหนดของวิธีประมูล ไม่ฝังในโค้ดหลายจุด | ✅ |

## ROOM — ห้องประมูล

| รหัส | Requirement | สถานะ |
|---|---|---|
| ROOM-01 | admin ต้องดูรายการ เพิ่ม แก้ไข ลบ ห้องได้ | ✅ |
| ROOM-02 | ห้องต้องมี ชื่อห้อง, รายละเอียด, **จำนวนผู้เข้าร่วมประมูลทั้งหมด** (สูงสุด), **จำนวนสินค้าประมูล** (สูงสุด) | ✅ |
| ROOM-03 | ลบห้องที่มี event ที่ยังไม่จบไม่ได้ | ✅ |
| ROOM-04 | ลดจำนวนผู้เข้าร่วม/จำนวนสินค้าต่ำกว่าที่มีอยู่ใน event ที่ยังไม่จบไม่ได้ | ✅ |
| ROOM-05 | ห้องที่เคยมี event ที่เริ่มแล้ว ต้องลบจริงไม่ได้ ให้ "เก็บถาวร" แทน (เลือกตอนสร้าง event ใหม่ไม่ได้ แต่ event เก่ายังอ้างถึงได้) | ⚠️ |

## EVT — การประมูล (event)

| รหัส | Requirement | สถานะ |
|---|---|---|
| EVT-01 | admin ต้องดูรายการ เพิ่ม แก้ไข ลบ event ได้ | ✅ |
| EVT-02 | event ต้องมี ชื่อ, ห้องประมูล, วิธีประมูล, เวลาเริ่ม, เวลาสิ้นสุด, สินค้า | ✅ |
| EVT-03 | จำนวนสินค้าใน event ต้องไม่เกินจำนวนที่ห้องรองรับ | ✅ |
| EVT-04 | เลือกสินค้าได้เฉพาะสถานะ "พร้อมขาย" และไม่อยู่ใน event อื่นที่ยังไม่จบ | ✅ |
| EVT-05 | เวลาสิ้นสุดต้องไม่เร็วกว่า เวลาเริ่ม + ระยะเวลายื่นราคาของวิธีประมูล | ✅ |
| EVT-06 | เวลาสิ้นสุดคือเวลาปิดห้อง (ผู้ใช้เข้าห้องไม่ได้หลังจากนั้น) ไม่ใช่เวลาปิดรับราคา — ปิดรับราคาเมื่อครบ 30 วินาทีนับจากเวลาเริ่ม (BID-02) | ✅ ดู open item O-1 |
| EVT-07 | สินค้าใน event เริ่มเป็น "อยู่ระหว่างการประมูล" เมื่อ event เริ่ม | ✅ |
| EVT-08 | event ที่เริ่มแล้วต้องแก้ไข (เวลา ห้อง สินค้า) หรือลบไม่ได้ ยกเลิกได้เฉพาะก่อนเริ่ม | ✅ |
| EVT-09 | admin ต้องดู **ราคาที่ผู้ใช้ทุกคนยื่น** ของแต่ละสินค้าใน event ได้ (ก่อนและหลังปิด) | ✅ |
| EVT-10 | event มีสถานะ ยังไม่เริ่ม → เปิดรับราคา → สรุปผลแล้ว (และ ยกเลิก) | ✅ |
| EVT-11 | event ที่ **ยกเลิกแล้ว** ต้องลบจริงไม่ได้เช่นกัน ถ้ามีผู้เข้าร่วมแล้ว (เก็บเป็นประวัติ) · ลบจริงได้เฉพาะ event ที่ยังไม่เริ่มและยังไม่มีผู้เข้าร่วม | ⚠️ |
| EVT-12 | ทุกครั้งที่ admin เปิดดูราคาที่ยื่น (EVT-09) ต้อง **บันทึกการเข้าดู** ว่า admin คนไหน ดู lot ไหน เมื่อไหร่ และอยู่ในช่วง **เปิดรับราคา** หรือหลังปิด (ดู `NFR-17`) | ⚠️ |

**เกณฑ์ตรวจรับ:** ใส่สินค้าเกินที่ห้องรองรับไม่ได้ · สินค้าชิ้นเดียวอยู่ 2 event พร้อมกันไม่ได้ · ราคาขั้นต่ำต่ำกว่าราคาเริ่มต้นแล้ว error · ลบสินค้าที่อยู่ระหว่างประมูลไม่ได้ · สินค้า/ห้อง/event ที่มีประวัติประมูลไม่มีปุ่มลบ และ request ลบตรงๆ ถูกปฏิเสธ · admin เปิดหน้าราคาที่ยื่นแล้วมีรายการใน audit log
