# 03 หน้าฝั่งผู้ใช้ (User Portal)

ใช้ได้เฉพาะผู้ใช้ที่ **ผ่านการตรวจคุณสมบัติแล้ว** (QUAL-05) ผู้ใช้อื่นถูกส่งไปหน้าสถานะ

| รหัส | Requirement | สถานะ |
|---|---|---|
| USR-01 | หน้าแรกต้องแสดง **banner โฆษณา** (เนื้อหาคงที่ ไม่ต้องมีหน้าจัดการ) และรายการสินค้าประมูล | ✅ |
| USR-02 | สินค้าแต่ละรายการในหน้าแรกต้องแสดง รูป, ชื่อ, **เวลาประมูล**, **ราคา (= ราคาเริ่มต้น)** | ✅ |
| USR-03 | หน้าแรกต้องแสดงเฉพาะสินค้าที่อยู่ใน event ที่ยังไม่สรุปผล (ยังไม่เริ่ม/กำลังประมูล) และสินค้า "พร้อมขาย" ที่ไม่อยู่ใน event ไม่ต้องแสดง | ✅ |
| USR-04 | คลิกสินค้าต้องเข้าหน้ารายละเอียด: รูปหลายภาพ, รายละเอียด, ราคาเริ่มต้น, เวลาประมูล, ห้อง | ✅ |
| USR-05 | หน้ารายละเอียดต้องมีปุ่ม **"เข้าร่วมประมูล"** ก่อนถึงเวลา | ✅ |
| USR-06 | การเข้าร่วมประมูลต้องทำได้ครั้งเดียวต่อสินค้า และยกเลิกได้ก่อนเริ่ม | ✅ (ยกเลิก) |
| USR-07 | จำนวนผู้เข้าร่วมทั้งหมดของ event ต้องไม่เกิน "จำนวนผู้เข้าร่วมประมูลทั้งหมด" ของห้อง เมื่อเต็มปุ่มเข้าร่วมต้องกดไม่ได้และแสดงข้อความ "เต็มแล้ว" | ✅ (นิยามจำนวนคน) / ✅ (พฤติกรรมตอนเต็ม) |
| USR-08 | ผู้ใช้เข้า **ห้องประมูล** ได้เมื่อถึงเวลาเริ่มของ event เท่านั้น และต้องเคยเข้าร่วมประมูลอย่างน้อยหนึ่งสินค้าใน event นั้น | ✅ (เข้าตอนถึงเวลา) / X (ต้องเข้าร่วมก่อน) |
| USR-09 | ในห้องต้องแสดง **รายการสินค้าที่อยู่ในประมูลของห้องนั้นขณะนั้น** พร้อมนับถอยหลัง | ✅ |
| USR-10 | ในห้องผู้ใช้ต้อง **กดเข้าร่วมประมูลสินค้าอื่นเพิ่มได้** ตราบที่ยังไม่ปิดรับราคา และห้องยังไม่เต็ม | ✅ / ✅ (เงื่อนไข) |
| USR-11 | ต้องมีหน้า **ผลการประมูล**: รายการสินค้าที่ผู้ใช้เข้าร่วม แสดงผล **ชนะ / ไม่ชนะ / ไม่ขาย** | ✅ |
| USR-12 | ผู้ใช้ทุกคนที่เข้าร่วมต้องเห็น **ราคาผู้ชนะ** ของสินค้านั้น แต่ต้องไม่เห็นว่าใครเป็นผู้ชนะ | ✅ |
| USR-13 | ผู้ใช้ต้องเห็นราคาที่ **ตนเองยื่น** ได้ ไม่เห็นราคาของผู้อื่นทุกกรณี | ✅ |
| USR-14 | การแจ้งผลทำที่หน้าผู้ใช้เท่านั้น (หน้าผลการประมูล) ไม่มี email/push | ✅ |
| USR-15 | ผู้ใช้ที่ชนะต้องเห็นว่าชนะ แต่ **ยังไม่มีปุ่มชำระเงิน** ใน M1 (ดู OOS-01) | ✅ |
| USR-16 | ต้องมีหน้า **"การประมูลของฉัน"** แสดง event ที่ผู้ใช้เข้าร่วม แยก 3 กลุ่ม: **ยังไม่เริ่ม** (สินค้าที่เข้าร่วม, นับถอยหลังถึงเวลาเริ่ม, ปุ่มยกเลิกการเข้าร่วมตาม USR-06) · **กำลังประมูล** (ปุ่ม **"เข้าห้องประมูล"** เด่นชัด) · **จบแล้ว** (ลิงก์ไปหน้าผลการประมูล USR-11) | ⚠️ |
| USR-17 | เมนูหลักฝั่งผู้ใช้ต้องมีลิงก์ไป "การประมูลของฉัน" และ "ผลการประมูล" ทุกหน้า · เมื่อ event ที่ผู้ใช้เข้าร่วมกำลังเปิดรับราคา หน้าแรกและหน้ารายละเอียดสินค้าต้องแสดงปุ่ม "เข้าห้องประมูล" ด้วย | ⚠️ |

**เกณฑ์ตรวจรับ:** กดเข้าห้องก่อนเวลาไม่ได้ · ห้องเต็มแล้วเข้าร่วมเพิ่มไม่ได้ · หน้าผลไม่แสดงชื่อ/ตัวตนผู้ชนะ และไม่แสดงราคาของผู้อื่นนอกจากราคาผู้ชนะ · ผู้ใช้ที่เข้าร่วมแล้วไปถึงห้องได้จากหน้า "การประมูลของฉัน" ภายใน 1 คลิกเมื่อถึงเวลา · ไม่มีหน้าใดแสดงราคาขั้นต่ำ (BID-18)
