# 07 ข้อที่ยังรอตัดสินใจ

ข้อที่มีผลต่อการออกแบบ ควรตอบก่อนเริ่มส่วนที่เกี่ยวข้อง ข้อที่ไม่มีคำตอบจะใช้ "ค่าตั้งต้น" ที่ระบุ

| # | คำถาม | ค่าตั้งต้น | กระทบ |
|---|---|---|---|
| O-1 | **เวลาสิ้นสุดของ event** คืออะไร: เวลาปิดห้อง (ปิดรับราคาตายตัว 30 วินาทีหลังเริ่ม) หรือเวลาปิดรับราคาจริง และสินค้าหลายชิ้นใน event เริ่ม/ปิดพร้อมกันหรือทยอยทีละชิ้น | ปิดห้อง · ทุกชิ้นเริ่ม/ปิดพร้อมกัน | EVT-05/06, BID-16, ตาราง events/lots |
| O-2 | อัปโหลดรูป: ชนิด/ขนาด/จำนวนสูงสุด | JPG/PNG/WebP, 5 MB, 10 รูป | ITEM-08 |
| O-3 | เป้าหมายผู้ใช้พร้อมกัน: สูงสุดกี่คนยื่นราคาพร้อมกันในช่วง 30 วินาที | ไม่กำหนด (ออกแบบให้ถูกต้องก่อน แล้ววัดภายหลัง) | NFR-16, การเลือก database (ปัจจุบัน SQLite) |
| O-4 | ฐานข้อมูล production: SQLite พอสำหรับการยื่นราคาพร้อมกันหรือไม่ หรือควรใช้ PostgreSQL | SQLite ตามที่โปรเจคตั้งไว้ ทบทวนหลังทดสอบโหลด | NFR-05, NFR-16 |
| O-5 | ผู้ใช้ยกเลิกการเข้าร่วมประมูลได้ก่อนเริ่มหรือไม่ | ได้ | USR-06 |
| O-6 | ผู้ใช้ที่ผ่านตรวจแล้วแก้ทรัพย์สินได้หรือไม่ (มีผลต่อเพดานราคา) | แก้ไม่ได้ใน M1 | QUAL-12 |
| O-7 | วงเงินนับแบบสะสมข้ามสินค้า หรือต่อครั้ง | ต่อครั้ง | BID-04 |
| O-8 | ผู้ใช้เข้าร่วมประมูลเพิ่มในห้องหลังเริ่มแล้วได้หรือไม่ (เหลือเวลารับราคาน้อยกว่า 30 วินาที) | ได้ จนกว่าปิดรับราคา | USR-10 |
| O-9 | จัดการบัญชี admin: ปิดใช้งาน/ลบได้ไหม, กันลบ admin คนสุดท้าย, admin มี fullname/email หรือไม่ | ปิดใช้งานได้ ลบไม่ได้ กัน admin คนสุดท้าย มีเฉพาะ username/password — **เขียนเป็น ADM-04–ADM-08 ตามค่าตั้งต้นนี้แล้ว** | AUTH-07, SUSP-09, ADM-* |
| O-10 | **ยืนยันใหม่:** ระงับผู้ใช้ระหว่างช่วงเปิดรับราคา ราคาที่ยื่นไว้แล้วยังนับ (ไม่ตัดสิทธิ์) — แก้จากที่เคยยืนยันว่า "ตัดออกจากการคัดผู้ชนะ" เพราะ admin เห็นราคาสดได้ (EVT-09) จึงระงับผู้ยื่นสูงสุดเพื่อเปลี่ยนผู้ชนะได้ | ราคาที่ยื่นแล้วนับเสมอ · การระงับกันแค่การยื่นใหม่ + ยกเลิกการเข้าร่วม lot ที่ยังไม่เริ่ม | SUSP-04, BID-17 |
| O-11 | USR-08 มีสถานะ "X" ที่ส่วน "ต้องเข้าร่วมก่อนจึงเข้าห้องได้" — หมายถึง **ปฏิเสธ** ข้อนี้ (ผู้ใช้ที่ผ่านตรวจทุกคนเข้าห้องได้เมื่อถึงเวลา) ใช่หรือไม่ ถ้าใช่ควรแก้ข้อความ USR-08 และเพิ่ม "X = ปฏิเสธ" ในคำอธิบายสถานะของ README | ยังไม่ตั้งค่า (ต้องตอบก่อนทำห้องประมูล) | USR-08, USR-16, BID-03 |
| O-12 | ช่องทางติดต่อผู้ดูแลที่แสดงให้ผู้ใช้ที่ถูกระงับ (SUSP-02) และผู้ที่ลืมรหัสผ่าน (AUTH-12) คืออะไร | ข้อความคงที่ (email/เบอร์โทรของผู้ดูแล) ตั้งค่าที่เดียวใน config | SUSP-02, AUTH-12 |

**ยืนยันแล้ว (ไม่ต้องถามอีก):** เสนอราคาครั้งเดียว · 30 วินาทีหลังเริ่ม · reserve กำหนดตอนเพิ่มสินค้า · เฉพาะ admin เห็นราคา · ราคาเท่ากันยื่นก่อนชนะ · ผู้ชนะคำนวณอัตโนมัติ · สินค้าอยู่ event เดียว · ผู้ใช้ที่ยังไม่ผ่านตรวจทำอะไรไม่ได้เลย (ทำได้เฉพาะ 4 อย่างตาม QUAL-05) · เก็บประวัติทุกรอบการส่งทรัพย์สิน · admin รีเซ็ตรหัสผ่านใน M1 · ระงับบัญชีได้ ~~และตัดราคาของผู้ถูกระงับออกจากการคัดผู้ชนะ~~ (ส่วนตัดราคากำลังเสนอแก้ ดู O-10) · ชำระเงิน/ส่งมอบไป M2
